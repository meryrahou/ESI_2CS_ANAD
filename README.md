# ESI 2CS Data Analysis Labs (ANAD)

## Overview

This repository encompasses the laboratory exercises from the Data Analysis course (ANAD) undertaken during the fourth year of the Computer Science program at the Ecole Nationale Supérieure d'Informatique (ESI), Algiers. The labs delve into advanced data analysis techniques, offering hands-on experience with various methods and algorithms.

## Repository Structure

The repository is organized into directories, each corresponding to a specific lab:

- `AFC/`: Analysis of Correspondence (AFC) — exploring relationships between categorical variables.
- `AFCM/`: Multiple Correspondence Analysis (AFCM) — extending AFC to more than two categorical variables.

Each lab directory contains:

- **Jupyter Notebooks**: Implementations of various data analysis techniques and methods.
- **Explanatory Materials**: Detailed instructions and explanations of the concepts covered.
